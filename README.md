## ✨ Flagship Engineering Highlights

1. **Apple Liquid Glass 3D Tilt & Specular Physics**:
   - Gobind's cinematic portrait hosted in an interactive glass card with dynamic specular glare, cursor raycasting, and 3 refraction presets (*Crystal*, *Frosted*, *Holo*).
2. **Interactive WebGL Liquid Fluid Shader Background**:
   - Real-time reactive fluid mesh reacting to mouse movement and ambient wavelength pulses.
3. **Interactive AI Lab & Terminal Simulators**:
   - **Sentix Multilingual Empathy Engine**: Facial emotion recognition simulation (DeepFace) with empathetic Llama 3 generation across 11 Indian languages (NLLB-200 distilled 600M).
   - **Medical AI Assistant (Clinical RAG with FAISS & Groq)**: High-performance cosine similarity retrieval over clinical literature with Groq 150+ tokens/sec inference and semantic citations.
   - **Decision Diary — Human-AI Memory Continuity System**: Local-first decision reflection engine with Ollama (Llama 3.1:8B) and browser vector storage (`thinkly_memories`) that secured **2nd Prize** at the GITA Chakravyuh Hackathon.
4. **Architectural Deep-Dive Modals**:
   - Comprehensive case study modals with interactive pipeline architecture diagrams, benchmarks, and GitHub repository links.
5. **Interactive Resume Viewer & 1-Click PDF Download**:
   - Direct embedded preview of `Gobind_Patel_Resume.pdf` and direct instant download.
6. **Web Audio Micro-Synthesizer & Ambient Soundscape**:
   - Ambient soundscape engine with live equalizer visualizer and Web Audio synthesizer.

## 🚀 Local Development

To run locally:

```bash
# Clone the repository
git clone https://github.com/GobindPatel2441/Portfolio-website.git
cd Portfolio-website/MyWebsite

# Start a local preview server
python -m http.server 5173
```
Then navigate to: `http://localhost:5173`
